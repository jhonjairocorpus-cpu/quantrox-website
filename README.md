# Quantrox Website

Sitio web de Quantrox Systems para presentar servicios de desarrollo web, software a medida, automatizacion empresarial y productos digitales.

Incluye enlace directo a la Suite Empresarial PWA:

https://jhonjairocorpus-cpu.github.io/suite-empresarial/

## Vista local

```powershell
python -m http.server 5180 --bind 127.0.0.1
```

Abrir:

```text
http://127.0.0.1:5180/
```

## Publicacion

Este repositorio puede publicarse como sitio estatico en GitHub Pages, Netlify, Vercel o el hosting del dominio principal.
